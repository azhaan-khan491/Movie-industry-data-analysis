# 🎬 Movie Industry Data Analysis using Python

## 📌 Project Overview

This project explores and analyzes a movie industry dataset using Python, Pandas, Matplotlib, and Seaborn. The objective is to uncover insights about movie ratings, genres, directors, actors, audience votes, gross income, and industry trends through data cleaning, analysis, and visualization.

---

## 🎯 Objectives

- Analyze movie ratings and audience preferences.
- Identify top-performing genres, directors, and actors.
- Explore relationships between ratings, votes, duration, and gross income.
- Discover hidden gems and overhyped movies.
- Perform exploratory data analysis (EDA) using Python.

---

## 💡 Key Insights

- Movie ratings show only a weak relationship with movie duration.
- Popular genres consistently attract more audience engagement.
- Certain directors and actors dominate movie production.
- Gross income is positively correlated with audience votes.
- Hidden gems exist with high ratings but low votes.
- Several movies receive high attention despite low ratings (overhyped movies).
